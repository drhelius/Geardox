# Enhanced DOSKEY for Geardox

Enhanced DOSKEY 2.0a, by Paul Houle, with a fix by Torsten Kühn, from http://paulhoule.com/doskey: command history,
editing, macros and Tab completion at MS-DOS's prompt. `doskey.cpp` holds its `DOSKEY.COM`, unmodified, as a byte array
and is generated by `build.sh`, not edited by hand.

Geardox writes it into `\GEARDOX` on the disks it makes with the user's own MS-DOS and loads it at the prompt. FreeDOS
disks don't have it: FreeCOM has its own history and completion, and doesn't call DOSKEY.

## Building

`build.sh` checks the package's hash, takes the program from it and writes `doskey.cpp`. It needs Python, and no
network.
